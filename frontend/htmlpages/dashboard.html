Guidelines for how to use this Website

Add a Complaint

  1. Upload a Photo: Add a clear image related to your issue (optional but useful).
  2. Enter Problem Description: Explain your issue clearly and concisely.
  3. Provide Location: Mention the exact place where the issue occurs.
  4. Mention Year of Problem: State when the problem started, if it's old.
  5. Submit Complaint: Click Submit to send your complaint to authorities.

View Complaint List

  1. Access List: View all complaints submitted by users.
  2. Search Complaint: Find a complaint using name or ID.
  3. Check Details: Read updates and status from authorities.

Check Complaint Status

  1. Enter Complaint ID: Enter your complaint ID for updates.
  2. View Status: See if it’s Pending, In Progress, or Resolved.
