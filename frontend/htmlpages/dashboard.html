Guidelines for Using This Website

How to Add a Complaint

  1. Select the correct problem type. If your issue is not listed, choose Other and enter your problem.
  2. Upload a clear image of the issue (optional but helpful).
  3. Write a clear and detailed description of the problem.
  4. Select the correct District and Village where the issue exists.
  5. Enter your complete address and click Submit Complaint.

How to Use My Complaint

  1. View all complaints you have submitted.
  2. Check the status: Pending (not started), In Progress (admin working), or Resolved (problem solved).
  3. You can edit or delete your complaint if required.
  4. See how many users supported your complaint and read their comments.

How to Use Complaint List

  1. View complaints submitted by other users in your area.
  2. Check complaint details, location, and current status.
  3. Click Support if you face the same issue.
  4. Add comments and read opinions from other users.
